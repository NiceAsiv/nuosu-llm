# Qwen3-8B Nuosu formal evaluation — 2026-07-29

## Decision

**FAIL — this checkpoint is not a release candidate.**

The final adapter does not produce stable Chinese or Nuosu text. Training loss
decreased, but held-out generation fails exact matching, nearly always reaches
the generation limit, and frequently emits Unicode replacement characters.
Do not describe the current adapter as a usable Nuosu model.

The local tokenizer round-trips Chinese, Nuosu, and mixed text without loss.
The cached official Base snapshot is
`49e3418fbbbca6ecbdf9608b4d22e5a407081db4`; model shard hashes match the
published files. The issue is therefore not a tokenizer mismatch or an
incomplete model download.

All four LoRA adapters contain 504 tensors and 87,293,952 elements. No adapter
contains NaN or Inf. RMS weight magnitude grows gradually from `0.00558` after
OCR CPT to `0.00696` after the final SFT, so there is no evidence of numerical
weight explosion.

## Interpretation

The current pipeline starts dialogue SFT from an unaligned Base model and never
passes a basic generation gate. The SFT losses around 3.4–4.8 are compatible
with partial token learning but not with reliable instruction following.
Additional low-resource data or another epoch should not be added to this
adapter chain until the basic generation path is repaired.

## Required next run

1. Archive the current adapters as failed experimental artifacts; do not reuse
   them as initialization for the next run.
2. Establish a clean `Qwen/Qwen3-8B` instruction-tuned baseline for SFT. Keep
   Base only for CPT experiments that first pass a plain-completion smoke test.
3. Add three mandatory gates:
   - the untouched starting model produces readable Chinese/English;
   - a 64-example SFT overfit test reaches low loss, emits `<|im_end|>`, and
     reproduces training targets;
   - a 192-example validation generation has low replacement-character and
     length-stop rates before any full run.
4. Train a small, high-quality bilingual instruction warm-up before the large
   dictionary projection. Mix general instruction data to prevent generation
   collapse.
5. Select learning rate, epochs, and decoding on validation only. Run the
   11,171-record held-out test once after the pipeline is frozen.
6. Before publication, add blind native-speaker review for accuracy,
   orthographic correctness, and fluency. Automated metrics cannot validate
   Nuosu naturalness.
