# Qwen3-8B Nuosu formal evaluation — 2026-07-29

## Decision

**INVALID — the cached Base checkpoint is corrupted.**

The final adapter does not produce stable Chinese or Nuosu text. Training loss
decreased, but held-out generation fails exact matching, nearly always reaches
the generation limit, and frequently emits Unicode replacement characters.
Do not describe the current adapter as a usable Nuosu model. These scores also
must not be used to judge the intended Qwen3 model or the corpus, because every
adapter was trained against damaged Base weights.

The local tokenizer round-trips Chinese, Nuosu, and mixed text without loss.

shards differ from the hashes encoded by the Hugging Face cache links:

The cached snapshot revision is
`49e3418fbbbca6ecbdf9608b4d22e5a407081db4`, but its shard contents are not the
published checkpoint contents. This is the primary cause of the unreadable
Base generations and invalidates all downstream adapters trained from it.

All four LoRA adapters contain 504 tensors and 87,293,952 elements. No adapter
contains NaN or Inf. RMS weight magnitude grows gradually from `0.00558` after
OCR CPT to `0.00696` after the final SFT, so there is no evidence of numerical
weight explosion.

## Interpretation

The current pipeline never checked the downloaded Base before launching CPT
and SFT. Since the Base shard contents are corrupted, training loss around
3.4–4.8 and downstream generation quality are not interpretable. Additional
data, epochs, or decoding changes cannot repair this adapter chain.

## Required next run

1. Quarantine the corrupted Base cache and every adapter trained from it. Do
   not reuse the current OCR, dictionary, short-SFT, or final adapters.
2. Download the Base into a new directory pinned to an explicit revision.
   Compute the actual SHA-256 of every shard and compare it with the published
   value before loading the model.
3. Run simple Chinese, English, and arithmetic generation checks on the clean
   untouched model. Do not start CPT until they produce readable continuations.
4. Establish a clean `Qwen/Qwen3-8B` dialogue baseline for SFT. Keep Base only
   for CPT experiments that pass the download and generation gates.
5. Add three mandatory training gates:
   - the untouched starting model produces readable Chinese/English;
   - a 64-example SFT overfit test reaches low loss, emits `<|im_end|>`, and
     reproduces training targets;
   - a 192-example validation generation has low replacement-character and
     length-stop rates before any full run.
6. Train a small, high-quality bilingual instruction warm-up before the large
   dictionary projection. Mix general instruction data to prevent generation
   collapse.
7. Select learning rate, epochs, and decoding on validation only. Run the
   11,171-record held-out test once after the pipeline is frozen.
8. Before publication, add blind native-speaker review for accuracy,
   orthographic correctness, and fluency. Automated metrics cannot validate
   Nuosu naturalness.
